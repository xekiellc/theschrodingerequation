Fault-counting estimator computes full logical sensitivity gradients in one simulation pass

A new differentiable estimator extracts error budget sensitivities from QEC simulations with 10–100× fewer samples than finite differences.

October 7, 2026

This is an unreviewed preprint posted to arXiv and has not yet undergone peer review. The authors present a method for efficiently computing logical sensitivities—partial derivatives of the logical error rate with respect to each physical noise parameter—in quantum error-correcting circuits. Where conventional approaches require separate Monte Carlo simulation runs at multiple noise configurations to approximate each partial derivative via finite differences, the proposed estimator recovers the entire gradient vector from a single simulation run by exploiting information about the underlying fault configurations that standard decoders already process.

Applied to surface code simulations under circuit-level noise, the estimator is reported to match finite-difference benchmarks while reducing the number of required shots by one to two orders of magnitude for equivalent statistical variance. The paper demonstrates several downstream applications: constructing per-error-type and per-qubit error budgets, inferring effective code distance from sensitivity data, and accelerating threshold searches in multi-parameter noise models by feeding sensitivities into a Newton root-finding procedure to locate and trace threshold contours without exhaustive parameter sweeps.

The technique is framed as an add-on to existing Monte Carlo QEC simulation pipelines rather than a replacement, since it operates on fault configuration data that decoders already generate. If the efficiency claims hold up to peer scrutiny, the method could meaningfully reduce the computational cost of hardware characterization and code optimization workflows where many partial derivatives across large noise models are needed.
